# NODEX ®

**The electronics magazine you can shop.**

NODEX is a concept e-commerce website for a tech store, designed like a 2000s electronics magazine: flip phones, CD players, handheld consoles and digicams, presented through covers, ads and editorial pages instead of a classic product grid.

🔗 **Live site:** https://0ph3li.github.io/NODEX/

---

## ✦ Pages

| Page | Description |
|------|-------------|
| `index.html` | Home, the magazine issue (cover, contents, ads) |
| `shop.html` | Full product catalogue |
| `new-in.html` | Latest arrivals |
| `deals.html` | Offers and discounts |
| `brands.html` | Brands we carry |
| `about.html` | Our story, told as an inbox of text messages |
| `contact.html` | Contact form |
| `search.html` | Product search |
| `bag.html` | Shopping bag |
| `faq.html`, `shipping.html`, `returns.html`, `privacy.html`, `terms.html` | Help and legal pages |

## ✦ Built with

- HTML, CSS and vanilla JavaScript (no frameworks)
- [GSAP](https://gsap.com/) + ScrollTrigger for scroll animations
- Google Fonts (Archivo, Bungee, VT323, Space Mono, Zen Kaku Gothic New and more)
- Hosted on GitHub Pages

## ✦ Project structure
NODEX/
├── index.html # home page
├── *.html # other pages
├── css/ # one stylesheet per page + style.css (shared)
├── js/ # one script per page + common.js and products.js
├── img/ # product and page images
└── VIBES/ # moodboard / visual references

## ✦ Run it locally

No installation needed: download or clone the repository and open `index.html` in your browser.
