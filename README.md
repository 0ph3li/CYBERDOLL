# CYBERDOLL ♡

**digital dolls, soft but lethal.**

CYBERDOLL is a concept fashion e-commerce website for a Y2K / cyber clothing brand: corsets, low-rise jeans, rhinestones and chrome, for girls who live half online and half in the club. The site mixes a real online shop with early-internet aesthetics: loading screens, MySpace-style profiles, a built-in radio and hidden secrets.

🔗 **Live site:** https://0ph3li.github.io/CYBERDOLL/

---

## ✦ Features

- **Drops system:** limited collections (Drop #004 ANGEL.EXE, Drop #005 MIDNIGHT MALL), no restocks
- **Full shop flow:** product pages, bag, wishlist, search and account
- **About page as a MySpace profile:** details, interests, blurbs and extended network
- **cyberdoll radio:** a music player built into the site
- **Lookbook and Journal:** editorial pages for each collection
- **Custom 404:** *DOLL NOT FOUND*
- **Hidden easter eggs:** find them to earn doll points and unlock customizations in your account ✧

## ✦ Built with

- HTML, CSS and vanilla JavaScript: no frameworks, no libraries
- Google Fonts: Anton, Pinyon Script, Playfair Display, Silkscreen, Space Mono
- Hosted on GitHub Pages

## ✦ Project structure
CYBERDOLL/
├── index.html # home page
├── *.html # other pages
├── css/ # style.css (shared) + one stylesheet per page
├── js/ # main.js (shared), products.js (catalogue data) + one script per page
├── img/ # product, lookbook and page images
├── VIBES/ # moodboard / visual references
└── EASTER EGGS/ # notes on the hidden secrets (ENG / ITA)

## ✦ Run it locally

No installation needed: download or clone the repository and open `index.html` in your browser.
